Windows file encryption

SimpleCrypt

A small, focused GUI tool for encrypting and decrypting files and folders with standard .NET symmetric algorithms.

Download latest release View source

Supported algorithms

AES-CBC16, 24, or 32-byte Key · 16-byte IV
DES-CBC8-byte Key · 8-byte IV
TripleDES-CBC16 or 24-byte Key · 8-byte IV
RC2-CBC5–16-byte Key · 8-byte IV

Highlights

  • Drag and drop files or folders.
  • Process folders recursively while preserving their structure.
  • No custom file header, archive format, or automatic algorithm detection.
  • Plain text and hexadecimal Key/IV input.

Key and IV format

Plain text is converted to UTF-8 bytes. Hexadecimal values may use hex: or 0x; spaces and hyphens are allowed.

0x0011 2233 4455 6677

SimpleCrypt targets .NET Framework 4.8 and is intended for Windows.
